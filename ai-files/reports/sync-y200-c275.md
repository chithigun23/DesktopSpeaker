## 1. Y200 (PCM1862 crystal)

Circuit as captured (netlist): Y200 pad 1 to U24 pin 10 XI and C226, pad 3 to U24 pin 9 XO and C227, pads 2/4 GND.
There is no series/damping resistor on XO. U24 is the I2S clock master from this crystal (plan section Source_Select_ADC).

PCM1862 datasheet (SLAS831D, `datasheets/PCM1862.pdf`):
- XI/XO are the on-chip crystal oscillator, XI is a 1.8 V-domain input. Table 4 allows a 15-35 MHz crystal. A 3.3 V
  CMOS clock would go to SCKI instead.
- Section 10.1.3: "connect to XI and XO, and add capacitors to ground, as suggested in the XTAL manufacturer's data sheet
  (typically 15 pF)". The EVM uses 24.576 MHz with 2 x 20 pF.
- 24.576 MHz = 512 fs at 48 kHz, so the PLL can stay off.

Original and previous parts:
- Lucki L327S240P11L, C5261154: LCSC lists it as **24 MHz**, the wrong frequency. Stock 0.
- JYJE 3TJ424576UYFBC, C2149067 (coordinator substitution): correct 24.576 MHz and CL 15 pF, but only 135 in stock.

Search (JLC parts list "24.576MHz", 300 hits, 3225-4P crystals filtered): no 24.576 MHz 3225 crystal with CL 15 pF has
more than 1000 in stock. The only other 15 pF part, Epson X1E0000210746 C255918, has 0.

Load capacitance with the existing 22 pF caps: CL = 22*22/44 + 3-5 pF stray = 14-16 pF. That matches a 15 pF crystal, but
it would be 2-4 pF high for a 12 pF one (roughly -20 to -45 ppm pull).

**Chosen: YXC X322524576MOB4SI, LCSC C70568** (`datasheets/YXC_YSX321SL_X322524576MOB4SI.pdf`, YSX321SL series)

| Parameter | Value |
|---|---|
| Frequency | 24.576 MHz fundamental |
| Load capacitance (CL) | 12 pF |
| Tolerance at 25 C | +/-10 ppm |
| Stability, -40 to 85 C | +/-20 ppm |
| ESR (16-31 MHz) | 50 ohm max |
| C0 | 3 pF max |
| Drive level | 10-200 uW (100 typ) |
| Aging | +/-3 ppm/yr |
| Package | 3.2 x 2.5 x 0.7 mm |
| Stock | LCSC 4,055, JLC list 5,135 |
| Price | $0.1042 at 5 (MOQ 5) |

- **Pads:** 1/3 crystal, 2/4 GND, land 1.4 x 1.2 mm at 2.2 x 1.7 mm pitch. That is identical to
  `Crystal_SMD_3225-4Pin_3.2x2.5mm` (pad 1 lower-left, counter-clockwise), so the footprint and copper are unchanged.
- **Load caps C226/C227 change 22 pF to 15 pF C0G:** Murata GRM1555C1H150JA01D, LCSC C76950, same Murata C0G 50 V +/-5%
  0402 series and footprint, 55,300 in stock, $0.0054 at 100.
  - New CL = 15*15/30 + 3-5 pF = 10.5-12.5 pF, centred about 0.5 pF under 12 pF (about +5 ppm).
  - Worst case is about +/-15-20 ppm from load mismatch, plus +/-10 ppm tolerance and +/-20 ppm temperature.
  - That is under +/-50 ppm (0.005 %), which is inaudible as pitch and fine for an I2S master ADC.
- **Startup margin:** lower CL helps the 1.8 V oscillator. The critical gm scales with ESR*(C0+CL)^2: 50*(3+12)^2 against
  60*(C0+15)^2 for the 15 pF JYJE part, about 40 % lower.
- **Not verified:** the PCM1862 oscillator's gm and drive level are not published. Check startup and frequency at bring-up;
  trim C226/C227 (15 pF to 18 pF lowers the frequency) only if the error is above about 20 ppm.
- Value fields changed only in the schematic, PCB and BOM: C226/C227 "22pF C0G" -> "15pF C0G". Y200 keeps "24.576MHz".
- Y200 Datasheet field (was empty) now links the YXC datasheet.
- Rejected alternatives with good stock: KYX K3A245761210 C19076851 (12 pF, 2,890; datasheet C0 5 pF max and 40 ohm,
  listing 30 ohm), YXC XL2EL89COI-111YLC C19711728 (same YSX321SL datasheet, 9,295), and 20 pF parts (would need
  33 pF caps and more oscillator gm).

BOM: `Y200` and `C226, C227` rows updated (Manufacturer/MPN/LCSC/price/stock/Availability/notes: old -> new, reason).

## 2. C275 3D model

Panasonic EEHZA1E101XP is size code **D8** (`datasheets/Panasonic_EEH-ZA_hybrid_polymer.pdf`, row 25 V 100 uF):

| Dimension | Value |
|---|---|
| D (body diameter) | 6.3 mm |
| L (height) | 7.7 +/-0.3 mm |
| A = B (base plate) | 6.6 mm |
| H (terminal tip to tip) | 7.8 mm max |
| I | 2.6 mm |
| W (terminal width) | 0.65 mm |
| P (terminal gap) | 1.8 mm |

The brief's "10 mm tall" does not apply: the datasheet height is 7.7 mm. The previous BOM note quoted P 2.2 and I 2.4 for D8;
the correct values are P 1.8 and I 2.6. The note is corrected.

**Land pattern:**
- The terminals run from about +/-0.9 to +/-3.9 mm.
- The `CP_Elec_8x10` pads (+/-3.25 mm, 3.5 x 2.5 mm, so +/-1.5 to +/-5.0 mm) cover 2.4 mm of each terminal.
- The 6.6 mm base sits inside the 8x10 courtyard.
- No land-pattern change was needed, so no new footprint was made and copper is unchanged.

**Model:** `kicad-library/3d/CP_Elec_6.3x7.7.step` (sha256 c2a2efc3...), copied unmodified from the installed KiCad library
(`org.kicad.KiCad.Library.Packages3D`, `Capacitor_SMD.3dshapes/CP_Elec_6.3x7.7.step`, kicad StepUp generator, CC-BY-SA 4.0
with the design exception). FreeCAD measurements (optimal bounding box and slices):

| Feature | Measured | Datasheet D8 |
|---|---|---|
| Body diameter at z 5 | 6.30 | D 6.3 |
| Base | 6.60 x 6.60 | A/B 6.6 |
| Height | 7.70 | L 7.7 |
| Terminal span | 7.80 | H 7.8 |
| Terminal width | 0.65 | W 0.65 |

- Origin is at the footprint centre with z 0 on the board.
- Terminals lie on the X axis, the same axis as the pads.
- The chamfered base corners and "+" are on the pad 1 (-X) side, with the negative band on the right.
- No offset, rotation or scale.
- No EasyEDA model was fetched, because this generic model matches every datasheet dimension.

**Repointing:** the model was changed on the C275 board footprint and in `kicad-library/footprint/CP_Elec_8x10.kicad_mod`.
C275 is the only user of that footprint: grep over all sheets and the board finds no other. The library and board stay
identical, so `lib_footprint_mismatch` is still 0. Pads, courtyard, silk and fab layers are unchanged. The schematic
Footprint field is unchanged (not required).

**Cosmetic leftover:** the silk outline is still the 8 x 8.3 mm outline around a 6.6 mm base. A dedicated footprint with a
6.3 mm silk outline is optional later. It would need a silk DRC re-check.

## 3. Schematic field sync with the BOM

Helper: `helpers/sync_y200_c275.py` (guarded, one-shot). Full diff list: `reports/sync-y200-c275-diff.json`.

- **Keying:** BOM rows are parsed by reference designator, with comma lists, ranges and "(R256 DNP)".
- **Rows skipped (no LCSC code or not a schematic part):** J5 mate housing and contacts, PACK, TP1-TP25, TP26-TP27. J7 (TC2030
  pads) is not in the BOM.
- **LCSC field:** the code goes into the symbol's existing `LCSC` and/or `LCSC Part` field. 20 symbols carry both, and both
  were set. If neither exists, an `LCSC` field is added as a hidden clone of the symbol's Footprint property.
- **Manufacturer, same company:** the schematic's long form is kept when the BOM names the same company differently. These
  were left as they are:
  - TI = Texas Instruments
  - ST = STMicroelectronics
  - Maxim = Analog Devices (U5)
  - Korean Hroparts Elec = Korean Hroparts (J1)
  - muRata/YAGEO/PANASONIC = Murata/Yageo/Panasonic
- **Manufacturer, new names:** written in canonical form with parenthetical notes stripped. D200/D201 get "DOWO", from the BOM
  text "DOWO (Nexperia PESD5V0S2BT equivalent)".
