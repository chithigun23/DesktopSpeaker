# Desktop Speaker project website (2026-11-02)

Static site source: `ai-files/website/desktopSpeaker-site/`, to be copied as a whole to
`~/mnt/website/desktopSpeaker/` by the coordinator. Every link is relative. At run time the only external
request is the Google Fonts stylesheet (IBM Plex Sans/Mono); the page falls back to system fonts without it.
three.js r128 (`three.min.js`, cdnjs) and its r128 `OrbitControls.js` and `GLTFLoader.js` (jsdelivr
`three@0.128.0/examples/js`) are vendored in `lib/`. Layout and styling follow the owner's inventoryCabinet
page (control strip, orbitable stage with side panel, cube widget, foldable sections, IBM Plex, the same
colour variables, light/dark), written anew; nothing of its geometry or code was copied. Nothing was written
in `~/mnt/website`. Not committed.

## The 3D viewer

Reads `cad/meta.json` and loads the glTF files it lists; without metadata it tries `cad/enclosure.glb` and
`cad/pcb.glb`; with no model it shows "CAD files not available yet" and points to the static renders.
Features: OrbitControls (drag, right/shift-drag pan, wheel/pinch, arrow keys, Home), CSS view cube and model
axes, Iso/Front/Rear/Top/Side views, group chips from `meta.groups` + `meta.pcb_group`, quick toggles (PCB,
enclosure, lid, battery, drivers), wireframe, see-through enclosure, explode slider (per-node `explode_mm`
replaces the group vector, so nothing moves twice; refit on release), X/Y/Z section sliders with flip, the 7
`section_planes` presets, optional files on demand (the 18 MB copper layer), hover highlight with the node
name (reference designators looked up in the BOM: value, function, MPN, LCSC, plus the 3D model source and
accuracy), screenshot PNG, reset. Spec panel from `key_dimensions` and `cad_status.json`; fit findings and
the interference result join the Verification table, CAD assumptions and open items join the notes and the
Open items table, CAD renders and downloads are listed first.

Adapting to the real v12 metadata needed: units strings with notes ("mm (root node ...)"), a PCB transform
already baked into the file (`note: already applied`: not applied twice), the separate `pcb_group`, an
`optional` file, and three.js node-name sanitising (`Insert_M3x5.7_...` loses its dot; without the fix 38 of
114 named parts were silently dropped). All 114 named nodes plus the PCB load (115 parts, 11 groups).

## BOM page logic (build_site_data.py)

- Rows from `DesktopSpeaker_LCSC_Starter_BOM.csv` (101 lines, 324 parts listed). Sheet and Value per row come
  from the schematic instance references in `DesktopSpeaker-kicad/*.kicad_sch` (348 references).
- Status: unresolved (no MPN: the pack), stock-zero (U1, U2, U19 on 2026-11-01), other-supplier (SW101,
  Digi-Key), below-order, substituted, in-stock, excluded (test points). Stock and dates are the CSV snapshots.
- Partial subtotal US$105.98 fitted / US$140.20 at order quantities, labelled not a product cost. Caveats shown
  above the table: partial subtotal, snapshot stock, U1/U2/U19 zero stock does not block hand assembly, pack
  unresolved. The CSV column headed "Accessed" holds a spreadsheet day number and "Cache age" the ISO date; the
  script reads either.
- The v11 STLs and zipped STEP are only published while `cad/downloads/` is absent (or with
  `--with-v11-cad`), so the newer v12 print files are not shadowed by stale ones.

## How to regenerate

```sh
python3 ai-files/helpers/build_site_data.py          # bom.json, files.json, downloads/, docs/, img/
```
Then copy the folder. `data/specs.json` is hand-curated: edit it (keep a `src` on every entry) when a report
changes. The routing page is a copy: recopy `ai-files/website/routing-progress/` into `routing/` and change
the back link to `../` when the recurring job updates it. The CAD agent refreshes `cad/`.

## Test evidence

Local `python3 -m http.server` on scratch ports, headless google-chrome (SwiftShader WebGL) driven by
`ai-files/helpers/site_cdp_test.py` (stdlib CDP client: console capture, clipped screenshots, scripted
clicks and pointer events). Step files and screenshots: `ai-files/reports/website-build-evidence/`.

| Case | Result |
| --- | --- |
| No `cad/` (nocad-view) | Overlay "CAD files not available yet"; viewer controls disabled; only the expected 404s |
| Stub CAD (`ai-files/pcb/work-site-test/`: box enclosure, RT-3 GLB via `kicad-cli pcb export glb`) | 14 parts, 8 groups; Z-up frame, mm and metre files, transform path exercised |
| Real CAD v12 (real-*, fin3-realq-view) | 115 parts in 11 groups, explode, x = 0 preset section, U3 hover: "STM32G071RBT6 · ST · C432213 · 3D model: KiCad library STEP · accuracy unverified"; optional copper loads (fin-cu-copper) |
| Content sections (nc-specs, nc-bom, nc-pcb, nc-ver) | Tables, filters, caveats, sources render; 57 documents, downloads with SHA256 |
| Dark theme (cad2-dark), forced theme button | Colours and 3D background follow the theme |
| Mobile 390 px (fin-m4-ctl) | Single column, no horizontal page overflow (only scrollable tables) |
| JavaScript console | No exceptions or console errors in any run |

Bugs found and fixed by testing: `.wrap` page class collided with table cells; long status tags and section
preset names widened the mobile page; partial `meta.nodes` coverage dropped parts; sanitised names; PCB
hover named sub-shapes (FRAME) instead of the reference; stale tooltip after a view change.

## Open, stubbed or not included

- The script lists, not copies, any datasheet over 5 MB (none in the current list); TPS61088 and PESD5V0S2BT datasheets are not in the
  repo. Reports are served as Markdown (plain text in the browser).
- The schematic preview PDF is the 2026-10-10 export.
- Specs carry the document conflicts the digest found (3 A vs 4 A charge cap: 4 A used; standby 35-40 uA vs
  57/105 uA: power analysis used; PCM1862 input codes; crystal caps); they are listed as an open item.
- Site size: 53 MB without `cad/` (docs 47 MB, of which datasheets most), `cad/` about 81 MB from the CAD
  export (its raw 37 MB STEP download dominates; zipping it would cut about 31 MB).
