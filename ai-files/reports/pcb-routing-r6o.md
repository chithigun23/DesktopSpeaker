## 2. USB full-speed waiver

The `usb_diff` rule now holds only the pair gap. The length constraints moved into a new rule `usb_fs_waiver` (rule 6b), scoped to `/USB_DP` and `/USB_DN`, with this comment block: 12 Mbps full speed; physical skew about 0.2 mm (KiCad skew includes via height); uncoupled 17.3 mm dominated by the J1 interleave, D1 and R171–R172 area; waived 2026-10-10.

- `diff_pair_uncoupled` max 6 → **18 mm** (actual 17.336 mm).
- `skew` max 0.5 → **3.5 mm** (actual 2.938 mm, DP 51.59 vs DN 54.53 incl. via heights).
- **Net-(U2-D+) / Net-(U2-D-) artefacts:** the −51.7 / −51.3 mm "skew" came from comparing the 3 mm U2 stubs with the 54 mm DN net. They clear because the length rule no longer applies to them.
- **Unchanged:** `diff_pair_gap` 0.15/0.15/0.25 (all USB class), `usb_pair_gap`, `width_audio` 0.25 and `usb_u2_entry`.
- **Rule checked to work:** with skew max 2 mm, DRC flags /USB_DP at 2.938 mm. With uncoupled max 17 mm, it flags 17.336 mm.
- **Strict DRC:** the `diff_pair_gap` pieces at 149.05, 57.83 (split artefacts at the pair ends) remain, as before.

**DRC: 0 errors, 0 unconnected.**

**Reproduction:**
1. `python3 route_r6o_silk.py R6o-0.kicad_pcb R6o-1.kicad_pcb --lib` (library edit once).
2. Add the `usb_fs_waiver` rule to `R6o.kicad_dru`.
3. `route_r6o_step.sh R6o-1 R6o-2 r6o/t3.json`
4. `… R6o-2 R6o-3 r6o/t4a.json`
5. `… R6o-3 R6o-4 r6o/t4b.json`
6. `… R6o-4 R6o-5 r6o/t4c.json`
7. Copy R6o-5 → R6o-final, then run `route_r6o_eval.sh R6o-final R6o-0 full`.
