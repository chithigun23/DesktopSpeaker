## 5. Rebuild
```
# one command (board + library copy; for v13 pass the corrected library folder)
ai-files/cad/v12/scripts/rebuild_cad.sh ai-files/pcb/work-route3/RT-3.kicad_pcb DesktopSpeaker-kicad/kicad-library \
    ai-files/cad/v12 ai-files/website/desktopSpeaker-site/cad ai-files/pcb/work-cad12
```
It runs, in order: `~/Applications/kicad.AppImage python3.11 ai-files/helpers/board_to_layout.py` (pcbnew), `~/Applications/kicad.AppImage kicad-cli pcb export step --force --subst-models --user-origin 147.25x88.8mm` (the outline centre is still x 147.25, y 88.8; the script stops if it moves), two `kicad-cli pcb export glb` runs, `freecadcmd build_speaker_cad.py`, `check_cad.py`, `fit_check.py`, `render_cad.py`, `export_enclosure_glb.py`, then `glb_repack.py`, `validate_glb.py` (python with numpy: a scratch venv, `PYVENV=`), checksums and `make_web_meta.py`. About 6 min. Never pass `python3` to the AppImage. The PNG previews come from a small three.js page (`preview.html?view=front|rear|top|exploded|section|section41|under|pcbonly`) rendered with `google-chrome --headless=new --no-sandbox --enable-unsafe-swiftshader --use-angle=swiftshader --window-size=2400,1500 --virtual-time-budget=60000 --screenshot=...` from a localhost http.server; the page is in the session scratchpad (`cad12_preview/`), not in the project.
